# Импорт заданий из ZIP

Короткая инструкция: как собрать архив с вопросами и залить их в курс **без** полного пересоздания базы.

## Зачем

- Агент или вы готовите `questions.json` + картинки.
- Одна команда или кнопка в панели ментора добавляет или обновляет вопросы в нужном модуле.
- Повторный импорт **не дублирует** вопросы с тем же названием — обновляет их.

## Импорт через сайт (для ментора / админа)

1. Войдите под ментором или администратором.
2. Откройте **Ментор** → вкладка **Редактор** (или сразу `#/mentor`).
3. Выберите курс в списке (например, «ЕГЭ-информатика»).
4. Раскройте блок **«Импорт пакета заданий»** (зелёная панель над структурой курса).
5. Перетащите ZIP или нажмите и выберите файл.
6. Нажмите **«Проверить (без записи)»** — увидите manifest, список уроков и сколько создастся/обновится.
7. Если всё ок — **«Импортировать в курс»**.

Ошибки показываются по-русски: нет manifest, не тот курс, модуль не найден и т.д.

Готовые архивы лежат в `content-packs/`:

| Архив | Задание |
|-------|---------|
| `ege-n1-import.zip` | ЕГЭ №1 — графы |
| `ege-n4-import.zip` | ЕГЭ №4 — кодирование |
| `ege-n7-import.zip` | ЕГЭ №7 — изображения |

Копии также копируются в `Desktop/BervinovVideos/import-packs/` при сборке (если папка есть).

## Структура ZIP

```
import.zip
  manifest.json      ← куда вешать пакет
  questions.json     ← вопросы (формат как на Desktop: Number1, Number4)
  images/            ← необязательно
    chart.png
```

## manifest.json (минимум)

```json
{
  "pack_id": "ege-n1-practice",
  "course_slug": "ege-informatika",
  "module_title": "1-й урок ЕГЭ: Графы"
}
```

| Поле | Зачем |
|------|--------|
| `pack_id` | Уникальный id пакета (латиница, цифры, `-`, `_`). По нему система помнит, какой модуль связан с пакетом. |
| `course_slug` | Slug курса в базе. Для ЕГЭ: `ege-informatika`. |
| `module_title` | Точное название модуля, куда кладём вопросы. |

### Дополнительно (по желанию)

```json
{
  "pack_id": "ege-n4-practice",
  "course_slug": "ege-informatika",
  "module_title": "Задание 4 — практика",
  "create_module": true,
  "module_description": "Вопросы по кодированию и Фано",
  "start_order_index": 20
}
```

| Поле | Поведение |
|------|-----------|
| `create_module` | `true` — создать модуль, если его ещё нет. `false` (по умолчанию) — ошибка, если модуля нет. |
| `module_description` | Описание нового модуля. |
| `start_order_index` | С какой позиции в модуле ставить вопросы. Если не указано — в конец. |

## questions.json

Тот же формат, что в папках `Number1` / `Number4` на Desktop:

```json
{
  "meta": {
    "topic": "ЕГЭ, задание 1",
    "images_dir": "images/"
  },
  "lessons": [
    {
      "type": "checkbox",
      "title": "Что такое граф",
      "question_text": "Отметьте верное…",
      "explanation": "Пояснение после ответа",
      "points": 4,
      "answers": [["Вариант A", true], ["Вариант B", false]]
    },
    {
      "type": "radio",
      "title": "Один правильный",
      "question_text": "Выберите…",
      "points": 3,
      "answers": [["Нет", false], ["Да", true]]
    },
    {
      "type": "short_answer",
      "title": "Число в ответе",
      "question_text": "Сколько?",
      "correct_answer": "26",
      "answer_normalize": "strip_casefold",
      "points": 3
    }
  ]
}
```

Типы: `checkbox`, `radio`, `short_answer` (также `theory`, `coding` — если нужны).

### Картинки к вопросу

Положите файлы в `images/` и укажите в вопросе:

```json
{
  "type": "radio",
  "title": "По схеме",
  "question_text": "Смотрите картинку…",
  "images": ["chart.png"]
}
```

При повторном импорте старые вложения этого вопроса заменяются.

## Команда

Из каталога `backend/` (или через `docker compose exec backend`):

```bash
python manage.py import_content_pack /path/to/import.zip
```

Проверка без записи в БД:

```bash
python manage.py import_content_pack /path/to/import.zip --dry-run
```

## Привязка к ЕГЭ №1 и №4

Сначала в базе должен быть курс (один раз):

```bash
python manage.py ensure_ege_course
```

| Задание | `module_title` в manifest |
|---------|---------------------------|
| ЕГЭ №1 (графы) | `1-й урок ЕГЭ: Графы` |
| ЕГЭ №4 (кодирование, Фано) | `2-й урок ЕГЭ: Кодирование и поиск` |
| ЕГЭ №7 (изображения) | `4-й урок ЕГЭ: Кодирование изображений` |

Пример manifest для №1:

```json
{
  "pack_id": "ege-n1-questions",
  "course_slug": "ege-informatika",
  "module_title": "1-й урок ЕГЭ: Графы"
}
```

Пример для №4:

```json
{
  "pack_id": "ege-n4-questions",
  "course_slug": "ege-informatika",
  "module_title": "2-й урок ЕГЭ: Кодирование и поиск"
}
```

ZIP из Desktop или из `content-packs/`: положите `questions.json`, добавьте `manifest.json`, при необходимости папку `images/`, заархивируйте. Или запустите `python content-packs/build_import_zips.py` — соберёт все три архива.

## Идемпотентность

- Один и тот же `pack_id` привязывается к модулю (метка в описании модуля).
- Каждый вопрос в модуле ищется по паре **тип + title**.
- Если уже есть — обновляется (ответы, текст, баллы).
- Если нет — создаётся.
- Полный `seed_data --clear` **не** вызывается.

## Ошибки

| Сообщение | Что сделать |
|-----------|-------------|
| Курс не найден | `python manage.py ensure_ege_course` |
| Модуль не найден | Проверьте `module_title` или `create_module: true` |
| Картинка не найдена | Файл должен лежать в `images/` внутри ZIP |
