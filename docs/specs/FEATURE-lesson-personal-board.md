# Картинка задания → личная доска

Статус: **APPROVED** владельцем в чате (17.08.2026). Код пишем сразу.

## Зачем

В задании 1 ЕГЭ нужна схема (граф + таблица). Рисовать прямо на каждом задании нельзя: на части уроков картинки нет, на части черновик не нужен.

Ученик видит картинку в задании. Если надо подумать карандашом — кнопка **«На личную доску»**. На доске появляется эта картинка, можно рисовать. Черновик на оценку не влияет и с задания не запоминается.

Видео-разбор — **после 3 ошибок**, как сейчас.

## Что видит ученик

1. Текст задания.
2. Картинки сразу на странице (не только «скачать»).
3. Кнопка «На личную доску» — **только если есть картинка** и доска включена.
4. Поле ответа, как раньше.
5. После трёх ошибок — разбор с видео.

На доске: «Картинка задания на доске. Рисуйте сверху. Это черновик.» Кнопка назад к уроку.

## Не делаем

- Рисовалку поверх каждого задания
- Сохранение рисунков на странице урока
- Автозапуск видео после первой ошибки
- Общую доску созвона для этой кнопки

## Техника

- Картинки — из уже существующих `attachments` (png/jpg/gif/webp/svg).
- Перенос: `sessionStorage` на один переход, затем личная tldraw-доска (`/whiteboard`).
- SVG можно прикреплять к заданию.
