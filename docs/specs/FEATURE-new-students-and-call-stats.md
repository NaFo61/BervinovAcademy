# Новые ученики у ментора и статистика звонков

Статус: **APPROVED** владельцем в чате (17.08.2026). Код пишем сразу.

## Зачем

Ментор сразу видит, кто **только что записался** на его курсы.

Владелец школы в админке видит **сколько было созвонов**, сколько завершилось и сколько шли по времени.

## Что получит человек

| Кто | Где нажать | Что увидит |
|-----|------------|------------|
| Ментор | Ментор → блок «Новые ученики» | Сколько новых за 7 дней, список: имя, курс, дата |
| Админ | Управление школой (`/admin`) | Карточки и таблица по дням по звонкам |
| Ученик | — | Этих экранов и API нет |

Пустой список у ментора: **«Пока нет новых учеников»**.

## Правила

- Новый ученик = запись на **курс этого ментора** за выбранное окно (по умолчанию 7 дней).
- Админ на странице ментора видит записи **по всем курсам**.
- Ментор **не** видит чужие курсы.
- Длительность звонка: если есть начало и конец — считаем разницу. Иначе не добавляем.
- «Идут» = статусы ожидание + сейчас идёт.
- Деплой: обычный CI на `main`, без `full-restart`. Сиды продакшена — отдельно.

## API (для разработки)

- `GET /api/mentoring/new-students/?days=7` — ментор и админ. `days`: `7` или `30`.
- `GET /api/communication/admin/call-stats/?days=7` — только роль `admin`.

## Вне скоупа

- Сиды продакшена
- Отдельное SPA для админки
- Графики звонков (Chart.js уже есть на дашборде школы, для звонков не подключаем)
- `full-restart.sh`
