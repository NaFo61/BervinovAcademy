# Telegram-бот: база

Статус: **база готова**. Чат с ментором через бота ещё не делаем.

## Зачем

Ученик привязывает Telegram к аккаунту на сайте. Потом бот сможет писать ему уведомления.

Вход через VK и Яндекс не трогаем. Бот сообщества VK убран.

## Что уже есть

- У пользователя: id Telegram, id чата, username, дата привязки.
- Одноразовый код на 30 минут. Ученик открывает бота и жмёт Start.
- Если этот Telegram уже привязан к другому аккаунту, повторная привязка не забирает его.
- Сообщения чата на сайте помечаются источником `site` или `telegram` (для будущего моста).

## Как привязать

1. В профиле кнопка «Привязать Telegram».
2. Открывается `https://t.me/<бот>?start=<код>`.
3. Бот шлёт на сайт событие `/start`. Сайт записывает привязку.

## Адреса API

| Метод | Адрес | Кто |
|--------|--------|-----|
| GET | `/api/telegram/status/` | вошедший пользователь |
| POST | `/api/telegram/link/` | выдаёт код и ссылку |
| DELETE | `/api/telegram/link/` | отвязывает |
| POST | `/api/telegram/webhook/<секрет>/` | Telegram |

В профиле те же данные приходят в `/api/users/me/` в поле `telegram`.

## Настройки

`TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` (без @), `TELEGRAM_WEBHOOK_SECRET`.

Адрес для Bot API:

`https://academy.bervinov-miron.ru/api/telegram/webhook/<TELEGRAM_WEBHOOK_SECRET>/`

Пока бот сам не вызывает `setWebhook` и не шлёт сообщения ученику. Это следующий шаг.
