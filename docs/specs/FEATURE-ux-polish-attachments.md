# Созвон, интерпретатор, файлы к заданиям, демо, мобильная вёрстка

Статус: **APPROVED** владельцем в чате (16.08.2026). Код пишем сразу.

## Зачем

Платформа должна ощущаться как живая школа: созвон без серых окон браузера, вывод Python как в терминале, файлы к заданию, нормальный демо-каталог, удобный телефон.

## Что делаем

1. Чиним найденные поломки (без большой перестройки).
2. Конец созвона — сводка внутри сайта. Завершить для всех может только ведущий. Остальные только выходят сами.
3. Вывод Python сохраняет переносы строк и отступы, ошибки красные.
4. Преподаватель прикрепляет файлы к **заданию** (не к домашней работе ученика). Файлы в том же S3, что видео и чат.
5. Сиды: живые тексты, баннер курса, аватары. Прод-базу не трогаем.
6. Мобильная вёрстка основных экранов (~390px).

## Созвон

- Нет `alert` / `confirm` / серого `beforeunload` на счастливом пути.
- После выхода или завершения: длительность, кто был, кнопка назад к уроку/курсу.
- API уже разделяет `POST …/end/` (ментор) и `POST …/leave/` (любой участник).

## Интерпретатор

- Pyodide больше не склеивает вывод в одну строку.
- Песочница/judge не выкидывает внутренние `\n` из stdout/stderr.
