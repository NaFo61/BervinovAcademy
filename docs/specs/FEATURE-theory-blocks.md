# FEATURE: Теория блоками (как на Степике)

Статус: **IMPLEMENTED** (2026-08-18). Владелец: «сделай это» + без лимита на число файлов.

## Зачем

Владелец собирает урок №1 так: **абзац → картинка → абзац → картинка**, без HTML.

Сейчас в теории одно большое текстовое поле. Картинки пачкой сверху. Нужный кадр нельзя вставить между словами.

## Что получит человек

В редакторе урока-теории:

1. Кнопка **«+ Текст»** — пишете обычный абзац.
2. Можно **выделить** кусок жёлтым маркером, сделать жирным или курсивом.
3. Кнопка **«+ Картинка»** — загружаете png/jpg/svg, пишете подпись («Шаг 2. Подписали степени»).
4. Кнопка **«+ Заголовок»** — следующий раздел.
5. Кнопка **«+ Важно»** — жёлтая рамка с предупреждением.
6. Стрелки вверх/вниз — поменять порядок.
7. Ученик видит то же сверху вниз: текст, картинка, текст.

Видео урока **не** внутри блоков: как сейчас, отдельным плеером.

## Acceptance criteria

- [x] В редакторе теории вместо одного HTML-поля — список блоков.
- [x] Типы блоков v1: `heading`, `text`, `image`, `callout`.
- [x] В тексте: жирный, курсив, жёлтый маркер. Без знания HTML.
- [x] Картинка грузится как сейчас (вложение урока), плюс **подпись**.
- [x] На странице урока блоки идут **в том порядке**, как в редакторе. Картинки теории **не** дублируются пачкой сверху.
- [x] У картинки теории кнопка **«На личную доску»**, если доска включена и ученик вошёл.
- [x] Старые уроки с одним HTML: открываются как **один текстовый блок**. После «Сохранить» живут уже блоками.
- [x] Некартиночные файлы (pdf и т.п.) по-прежнему списком «Материалы» внизу.
- [x] Задания (radio / checkbox / краткий ответ / код) **не меняются**: схема КИМа как сейчас, пачкой у условия.
- [x] Число файлов и блоков **без потолка**. Размер одного файла — до 20 МБ.
- [x] Pytest: сохранение блоков, санитайз HTML, картинка только своего урока, ученик видит `blocks`, старый `content` без блоков всё ещё читается.

## User stories

1. Как преподаватель, я пишу «Сначала смотрим схему», гружу картинку, пишу «Теперь считаем степени», гружу вторую картинку — и так дальше.
2. Как преподаватель, я жёлтым маркером выделяю фразу «буквы не равны номерам».
3. Как ученик, я читаю урок сверху вниз и вижу картинку **там, где о ней речь**.
4. Как ученик со старым уроком (ещё без блоков), я вижу прежний HTML, страница не пустая.

## Как устроено сейчас (as-is)

| | |
|--|--|
| Текст теории | `LessonTheory.content` — HTML, в редакторе textarea |
| Картинки | `LessonAttachment`, на странице **все** картинки сверху («Схема к заданию») |

| Редактор | `PATCH /api/mentoring/editor/lessons/theory/{id}/` поле `content` |

## To-be

### Блоки

Поле JSON у теории, например `blocks`:

```json
[
  {"id": "…", "type": "heading", "text": "Что дают в №1"},
  {"id": "…", "type": "text", "html": "<p>В условии схема и таблица. <mark>Буквы ≠ номера</mark>.</p>"},
  {"id": "…", "type": "image", "attachment_id": "<uuid вложения>", "caption": "Исходная схема и таблица"},
  {"id": "…", "type": "callout", "html": "<p>Схему и таблицу рисовали независимо.</p>"},
  {"id": "…", "type": "text", "html": "<p>Дальше считаем степени.</p>"}
]
```

| Тип | Поля | На экране |
|-----|------|-----------|
| `heading` | `text` | Заголовок раздела |
| `text` | `html` | Абзац. Разрешено: `p`, `br`, `strong`, `em`, `mark`, `ul`, `ol`, `li` |
| `image` | `attachment_id`, `caption` | Картинка + подпись. Файл уже есть в `attachments` |
| `callout` | `html` | Жёлтый блок «Важно» |

- `id` блока — uuid, чтобы не путать при сдвиге вверх/вниз.
- Потолка по числу блоков и файлов **нет**.
- `attachment_id` обязан быть вложением **этого** урока и картинкой (png/jpg/gif/webp/svg).

### Поле `content`

Не удаляем.

- Если `blocks` непустой — ученику показываем **блоки**. `content` при сохранении редактора пересобираем из блоков (простой HTML), чтобы ничего не сломать снаружи.
- Если `blocks` пустой/null — ученику старый `content`, как сейчас.

### API

Без новых URL урока.

| Method | Path | Изменение |
|--------|------|-----------|
| GET | `/api/content/...` detail теории | + `blocks` (массив). В `image` дополнительно `url` картинки (как у attachments). |
| GET/PATCH | `/api/mentoring/editor/lessons/theory/{id}/` | + `blocks`. Картинки по-прежнему `POST …/attachments/`. |
| POST | `…/attachments/` | без изменений: сначала файл, потом блок ссылается на `public_id`. |

Ошибки PATCH:

- неизвестный `type` → 400
- чужое/не картинка `attachment_id` → 400
- HTML чистим тем же санитайзом, что сейчас (плюс `mark`)

Удаление вложения: если на него ссылается блок `image` — блок тоже убрать (или 400 «сначала уберите блок»). **Делаем так:** при DELETE вложения выкидываем блоки, которые на него ссылались.

### DB

- `LessonTheory.blocks` — `JSONField`, default `list`, blank ok.
- Миграция: существующие уроки `blocks=[]`, текст остаётся в `content`.
- Новых таблиц нет. Картинки — существующий `LessonAttachment`.

### UI

**Редактор (`content-editor.jsx`), только `kind === theory`:**

- Список карточек-блоков.
- Панель блока: вверх, вниз, удалить.
- Между блоками и внизу: **+ Текст / + Картинка / + Заголовок / + Важно**.
- Текст и «Важно»: поле ввода + кнопки Жирный / Курсив / Маркер (оборачивают выделенное).
- Картинка: превью, подпись, «Заменить файл».
- Старое поле «Содержание (HTML)» **убрать** для теории.
- Общий список «Файлы к заданию» для теории: оставить только **не-картинки** (pdf и т.д.). Картинки живут как блоки.

**Урок (`learn.jsx`):**

- Рендер блоков сверху вниз (после видео).
- Нет галереи «Схема к заданию», если есть блоки.
- Подпись под картинкой. Кнопка доски — на каждой картинке.
- Стили `mark` — жёлтый фон, не кислотный.

Мобильная вёрстка: картинка на ширину экрана, кнопки редактора не обрезать.

### Тесты

1. PATCH blocks → GET ученика отдаёт те же типы/порядок.
2. `text.html` со `<script>` — скрипт вырезан, `mark` остаётся.
3. `attachment_id` другого урока → 400.
4. Урок с пустым `blocks` и старым HTML → ученик видит HTML.
5. DELETE картинки → блок image с этим id исчезает.
6. Редактор/ученик: картинки теории не дублируются отдельной галереей, если blocks непустой.

## Deploy impact

- Миграция `content` (`blocks` у теории).
- Пересборка backend + frontend image, `restart.sh`.
- Новых секретов нет.
- Прод-уроки не переписываем автоматически: старый HTML жив, пока не откроете и не сохраните.

## Out of scope

- Задания (radio, checkbox, short-answer, coding) — условие как сейчас.
- Видео внутри блоков, код внутри блоков, квиз внутри теории.
- Перетаскивание мышью (только стрелки вверх/вниз).
- Редактор Word / TinyMCE / новый npm-стек (Vite, TipTap).
- Автосбор картинок из сценария ЕГЭ.
- Размер одного файла больше 20 МБ (лимит сервера на файл, не на количество).

## Decisions (предлагаем закрыть так)

1. **Только теория** в этой итерации.
2. **Четыре типа блоков:** заголовок, текст, картинка, важно.
3. **Выделение** = жёлтый маркер внутри текста + блок «Важно».
4. **Картинки** = уже существующие вложения, не отдельное хранилище.
5. **Порядок** = стрелки, не drag-and-drop.
