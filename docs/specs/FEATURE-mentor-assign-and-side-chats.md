# FEATURE: Назначение ментора + быстрые чаты на уроке

Status: **APPROVED** (владелец: «делаем», срочная поставка)

---

## Зачем

Пока ученик решает задачу, ему нужно быстро:

1. Написать **своему ментору**.
2. Спросить **ИИ-помощника** про текущий урок/задачу.

Ментора можно назначить ученику. Если не назначен — берём администратора (или первого admin).

---

## Что получит человек

| Кто | Что |
|-----|-----|
| Ученик на странице урока | Кнопка помощи → боковая панель с вкладками «Ментор» и «ИИ-помощник» |
| Ментор / админ | Может назначить ментора ученику (панель ментора + API) |
| Все | Чат с назначенным ментором без лишних шагов |

---

## Правила

- У каждого студента есть **назначенный ментор** (поле на профиле студента).
- Если поле пустое → **дефолт**: первый активный пользователь с ролью `admin`.
- Запасной вариант: ментор курса, на который студент записан.
- Чат с **своим** (resolved) ментором — всегда доступен студенту (не блокируем тарифом Про).
- Старый путь «открыть чат по курсу / другому ментору» — как раньше (Про + запись на курс).
- ИИ: отвечает **в контексте текущего урока** (название, тип, формулировка). Без ключа — демо-заглушка. С ключом OpenAI-compatible — опциональный реальный вызов.

## API (для разработки)

### Ментор

- `GET /api/mentoring/my-mentor/` — кто мой ментор + source (`assigned` / `course` / `default_admin`)
- `GET /api/mentoring/assignable-mentors/` — список mentor|admin (для назначения)
- `POST /api/mentoring/students/<user_public_id>/assign-mentor/` — body `{ "mentor_public_id": "..." | null }`
- В списке учеников курса — поле `assigned_mentor` (кратко)

### Чат

- `GET /api/communication/chat/threads/open/?assigned=1` — открыть/создать диалог со своим ментором

### ИИ-помощник

- `POST /api/mentoring/assistant/chat/`  
  body: `{ message, history[], context: { lesson_kind, lesson_title, lesson_statement, course_title } }`  
  response: `{ reply, mode: "mock"|"llm", model? }`

Env (опционально): `ASSISTANT_LLM_ENABLED`, `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL`.

## UI

- На `#/learn?...` — плавающая кнопка «Помощь».
- Drawer справа: вкладки **Ментор** | **ИИ-помощник**.
- Ментор: существующий `ChatThreadView` (WebSocket уже есть).
- ИИ: простой чат; контекст урока показывается сверху.

В панели ментора (вкладка «Ученики»): выбрать ментора из списка.
