Задание 23 ЕГЭ: сколько программ у исполнителя

Исполнителю дают стартовое число и две или три команды. Нужно узнать, сколькими разными программами он приходит из старта в цель. Программа — это последовательность команд. Две программы различны, если команды шли в другом порядке, даже если промежуточные числа где-то совпали.

Выписывать все цепочки имеет смысл, пока их пять-шесть. Дальше их десятки, и мы переходим на столбик: в клетке n стоит, сколькими способами в это n вообще можно прийти.

Игрушка: из 1 в 6, команды +1 и ×2

Старт 1. Команды прибавить 1 и умножить на 2. Цель 6. Ниже все маршруты, каждый начинается с единицы.

  • 1 —+1→ 2 —+1→ 3 —+1→ 4 —+1→ 5 —+1→ 6
  • 1 —+1→ 2 —+1→ 3 —×2→ 6
  • 1 —+1→ 2 —×2→ 4 —+1→ 5 —+1→ 6
  • 1 —×2→ 2 —+1→ 3 —+1→ 4 —+1→ 5 —+1→ 6
  • 1 —×2→ 2 —+1→ 3 —×2→ 6
  • 1 —×2→ 2 —×2→ 4 —+1→ 5 —+1→ 6

Их шесть, и все шесть разные. Из единицы обе команды попадают в двойку, поэтому числа в начале совпадают. Отличие в подписи над стрелкой: где-то первая команда +1, где-то ×2. Теперь тот же ответ столбиком, чтобы было с чем сверять. В единицу мы «пришли» одним способом: уже стоим на старте, ни одной команды не сделали. В двойку можно прийти из 1 двумя командами, +1 и ×2, поэтому в клетке 2 стоит 1+1 = 2. В тройку ×2 не ведёт ниоткуда целым числом, только +1 из двойки, поэтому тоже 2. В четвёрку ведут +1 из тройки (2 способа) и ×2 из двойки (2 способа), вместе 4.

У шестёрки в таблице тоже 6. Список и столбик сошлись. До десятки тем же правилом получается 14. Эти 14 маршрута мы уже не выписываем: правило проверено на шестёрке.

Из 1 в 6: 6. Из 1 в 10: 14.

План

  1. В стартовой клетке пишем 1.
  2. Идём по числам слева направо.
  3. В очередное число складываем способы всех тех чисел, из которых в него есть команда.
  4. Если команда перескакивает через число, в перескоченное ничего не добавляем этой командой.
  5. Ответ — клетка цели. Если какое-то число запрещено, в нём пишем 0 и из него никуда не ходим.

Пример 1. Семёрка запрещена

Вопрос. Те же команды +1 и ×2, старт 1, цель 10. В траектории нельзя иметь число 7. Сколько программ?

До шестёрки запрет ничего не ломает: семёрки там нет, числа те же, что в игрушке. В самой семёрке пишем 0, даже если из шестёрки команда +1 в неё просится. Из нуля ходы не продолжаем. Восьмёрка раньше получала и из четвёрки (×2), и из семёрки (+1). Вклад семёрки теперь 0, остаётся только четвёрка: 4 способа. Десятка собирается из девятки командой +1. Девятка — только из восьмёрки. Поэтому десятка равна восьмёрке и равна 8? Проверим таблицу, а не эту догадку в одну фразу.

Пример 2. Команды +1 и +2

Вопрос. Старт 1, команды прибавить 1 или прибавить 2. Сколько программ приводит в 8?

Умножения нет, зато в каждое число, начиная с тройки, обычно входят два предыдущих. Сначала сверим четвёрку списком. Маршрутов три:

  • 1 —+1→ 2 —+1→ 3 —+1→ 4
  • 1 —+1→ 2 —+2→ 4
  • 1 —+2→ 3 —+1→ 4

В таблице у четвёрки тоже 3: из тройки и из двойки. Дальше клетка равна сумме двух предыдущих. Это похоже на ряд 1, 1, 2, 3, 5… только сдвинутый. До восьмёрки доводим таблицей, не списком.

Коротко, чтобы запомнить

  1. Ответ — число программ, не число, которое получится в конце. Конец и так дан.
  2. В старте всегда 1, если старт не запрещён.
  3. Клетка складывает способы тех, кто в неё шагает, а не способы всех меньших чисел подряд.
  4. Короткий список маршрутов нужен один раз, чтобы поверить таблице.
  5. Запрещённое число — это 0. Через него маршрут не идёт, даже если команда туда попадает.

Сколько программ, не какое число получится

В клетке n лежит число способов до неё добраться. Старт равен 1. Дальше каждая команда прибавляет способы текущей клетки к клетке, куда она ведёт. Запрещённое число обнуляют и из него не ходят.

Второй прототип — рекурсия с ветками +1, ×2 и ×3, как в коротких задачах «из a в b». Условие отсечения a == 14 выкидывает маршруты через запретное число. Кэш не меняет ответ, он не даёт считать одну и ту же пару дважды.

Рабочие программы к этому уроку

Каждый фрагмент запускается отдельно. В конце он печатает ответ. Комментарии на русском говорят, какая строка за что отвечает.

n23-to6

start = 1  # МЕНЯТЬ: старт
goal = 6  # МЕНЯТЬ: цель
ways = [0] * (goal + 1)
ways[start] = 1
for n in range(start, goal + 1):
    if ways[n] == 0:
        continue
    if n + 1 <= goal:  # МЕНЯТЬ: команда +1
        ways[n + 1] += ways[n]
    if n * 2 <= goal:  # МЕНЯТЬ: команда ×2
        ways[n * 2] += ways[n]
print(ways[goal])

Что менять, если условие другое.

  • start = 1 # МЕНЯТЬ: старт
  • goal = 6 # МЕНЯТЬ: цель
  • if n + 1 <= goal: # МЕНЯТЬ: команда +1
  • if n * 2 <= goal: # МЕНЯТЬ: команда ×2
  • Печать в конце оставляют: это и есть ответ.

n23-ban7

start, goal = 1, 10
banned = {7}  # МЕНЯТЬ: запрещённые числа
ways = [0] * (goal + 1)
ways[start] = 1
for n in range(start, goal + 1):
    if n in banned:
        ways[n] = 0  # через запрет не ходим
        continue
    if n + 1 <= goal and (n + 1) not in banned:
        ways[n + 1] += ways[n]
    if n * 2 <= goal and (n * 2) not in banned:
        ways[n * 2] += ways[n]
print(ways[goal])

n23-cut

from functools import lru_cache

@lru_cache(None)
def f(a, b):
    # Сколько программ из a в b. Ветки +1, *2, *3.
    if a == b:
        return 1
    if a > b or a == 14:  # МЕНЯТЬ: 14 — число, через которое нельзя
        return 0
    return f(a + 1, b) + f(a * 2, b) + f(a * 3, b)

print(f(2, 39))  # МЕНЯТЬ: старт и цель

  • Печать в конце оставляют: это и есть ответ.
