# Что загрузить сейчас

На сайт уходит **по одному ZIP**. Папка: `content-packs/к-импорту/`.

Сейчас нужны только эти пять файлов, по порядку:

| Файл | Куда попадёт |
|------|----------------|
| `01-ege-n1-import.zip` | модуль «1-й урок ЕГЭ: Графы» — уроки 1.1, 1.2, 1.3 |
| `02-ege-n2-import.zip` | модуль «Задание 2 ЕГЭ: Логика» — уроки 2.1, 2.2, 2.3 |
| `03-ege-n3-import.zip` | модуль «Задание 3 ЕГЭ: Базы данных» — уроки 3.1, 3.2, 3.3 |
| `04-ege-n4-import.zip` | модуль «2-й урок ЕГЭ: Кодирование и поиск» — уроки 4.1, 4.2, 4.3, 4.4 |
| `24-ege-n24-import.zip` | модуль «Задание 24 ЕГЭ: строка символов» — уроки 24.1–24.6 |

Остальные архивы в папке (5–23, 25–27 и контрольные) сейчас не загружайте. Общий `content-packs.zip` тоже не нужен.

## Куда на сайте

1. Войдите как ментор.
2. Ментор → курс «ЕГЭ-информатика» → вкладка **Редактор**.
3. Блок **«Импорт пакета заданий»**.
4. Выберите один ZIP → **Импортировать в курс**.
5. Так же следующие четыре файла.

Урок с тем же названием обновится. Новое название появится рядом со старым, пока сайт не обновлён.

Старые квадратики в этих модулях можно скрыть: откройте урок и нажмите **Скрыть**. Кнопки «Удалить» на списке появятся после обновления сайта.
