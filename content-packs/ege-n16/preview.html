Задание 16 ЕГЭ: рекурсия

Сегодня разберём задание, где дана функция, и эта функция вызывает сама себя. Спрашивают одно число — чему равно F(какое-то n) — или сколько таких n, у которых F(n) обладает свойством: чётное, делится на 3, больше ста.

Приём один и тот же. Не прыгаем сразу к тому n, которое спросили. Пишем столбик от самого маленького значения к большому. Каждая новая строка опирается только на строки выше. Сначала так сделаем на короткой функции, потом решим четыре задачи.

Что такое рекурсия

Рекурсия — это когда в правиле для F(n) снова написано F, но уже с меньшим числом: F(n−1), F(n−2) или F(n/2). Меньшим — обязательно. Иначе цепочка не кончается.

В начале правила всегда есть стоп. Это строка вида «если n равно 1, ответ такой-то». Дошли до стопа — дальше функцию не вызываем, просто пишем готовое число.

На экзамене функцию дают текстом программы. Нам не нужно её запускать на компьютере. Нужно честно заполнить таблицу. Калькулятор пригодится только чтобы сложить уже написанные числа, а не чтобы угадать ответ.

Игрушка: прибавляем само n

Правило короткое.

  • если n = 1, ответ 1;
  • иначе ответ равен F(n−1) + n.

Спросили бы F(6). Шестёрку сразу писать нельзя: для неё нужно F(5), для пятёрки — F(4), и так до единицы.

Читаем последнюю строку: F(6) = 15 + 6 = 21. Промежуточные 3, 6, 10, 15 сами по себе ответом не являются, но без них последняя строка пустая.

Заметить, что тут выходит сумма 1+2+3+4+5+6, можно. На экзамене правило будет другим, и красивой формулы может не быть. Привычка одна: строка под строкой.

План на любую такую задачу

  1. Находим стоп и выписываем его первой строкой. Иногда стопов два: отдельно для 1 и для 2.
  2. Дальше n идёт по порядку: 3, 4, 5… Не перескакиваем.
  3. Смотрим, чётное число или нет, если в правиле развилка. Подставляем только те F, которые уже стоят в таблице.
  4. Если просят одно значение — это последняя нужная строка. Если просят «сколько» — добавляем столбец «подходит?» и считаем отметки.

Пример 1. Чётное складываем, нечётное вычитаем

Вопрос. Чему равно G(8)?

Правило:

  • G(1) = 1 и G(2) = 2 — это два стопа;
  • если n нечётное и больше 2, G(n) = G(n−1) − G(n−2);
  • если n чётное, G(n) = G(n−1) + G(n−2).

Для тройки n нечётное, поэтому вычитаем уже известные G(2) и G(1): 2 − 1 = 1. Для четвёрки n чётное, складываем G(3) и G(2): 1 + 2 = 3. Минус здесь не «отрицательная куча», а обычное вычитание двух уже посчитанных чисел. Пока меньшее вычитается из большего, результат положительный — так и задумано в этом примере.

Пример 2. Чётное режем пополам

Вопрос. Чему равно F(13)?

Правило другое. Стоп один: F(1) = 1. Если n чётное, пополам не делим «ответ», а вызываем функцию от n/2: F(n) = F(n/2). Если n нечётное, единицы прибавляем к предыдущему: F(n) = F(n−1) + 1.

Двойка чётная, значит F(2) = F(1) = 1. Тройка нечётная: F(2) + 1 = 2. Четвёрка снова чётная, и половина четвёрки — это 2, а F(2) мы уже писали, оно равно 1. Поэтому F(4) = 1, а не 2.

Пример 3. Сколько значений делится на 3

Вопрос. Сколько чисел n от 1 до 20 таких, что F(n) делится на 3?

Правило: если n меньше 3, ответ равен самому n. Иначе F(n) = F(n−1) + F(n−2). То есть каждая строка — сумма двух предыдущих.

F(1) = 1, F(2) = 2. Дальше 1+2 = 3, 2+3 = 5, 3+5 = 8, 5+8 = 13. Уже видно, зачем столбец «делится на 3»: тройка делится, пятёрка нет, восьмёрка нет. Не останавливаемся на десятке, потому что спросили до 20.

Пример 4. В чётном шаге делим аргумент

Вопрос. Чему равно F(12)?

  • F(1) = 2;
  • если n чётное, F(n) = F(n/2) + n;
  • если n нечётное, F(n) = F(n−1) + 1.

Ошибка, которую здесь легко сделать: при чётном n прибавить n не к F(n/2), а к F(n−1). В правиле написано именно n/2. Для шестёрки половина — это 3, F(3) уже есть и равно 5, поэтому F(6) = 5 + 6 = 11. Для двенадцати половина — 6, берём только что полученную 11 и прибавляем 12.

Коротко, чтобы запомнить

  1. Сначала стоп. Пока его нет в таблице, считать нечего.
  2. n увеличивается на 1. Строка пользуется только верхними строками.
  3. Развилка «чётное / нечётное» решается для текущего n, не для ответа.
  4. Деление n пополам — это другой аргумент функции, его тоже надо сначала посчитать.
  5. Вопрос «сколько» — это лишний столбец и число отметок, а не новое правило.
