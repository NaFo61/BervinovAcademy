Задание 19 ЕГЭ: игра, победа за один ход

Задания 19, 20 и 21 — одна игра, три вопроса. Есть куча камней. Двое ходят по очереди, Петя начинает. За ход кучу изменяют одной из разрешённых команд. Побеждает тот, кто первым доведёт число камней до заданной границы или дальше.

В девятнадцатом спрашивают самое маленькое стартовое число, с которого Петя побеждает своим первым ходом. То есть одним действием сразу перешагивает границу. Чужой умной игры тут ещё нет: надо просто посмотреть, из каких куч граница достижима за шаг.

Игрушка: дотянуть до 10

Граница — 10. Команды две: прибавить 1 или умножить на 2. Петя побеждает сразу, если после его хода камней стало не меньше 10.

Из 4: 4+1 = 5 и 4×2 = 8. Обе меньше 10, сразу победить нельзя. Из 5: 5×2 = 10, граница взята. Из 9 хватает даже +1. Значит самые левые такие кучи начинаются с пятёрки, и минимальная как раз 5.

В таблице выше колонка «что это значит» заглядывает вперёд, в задания 20 и 21. Для девятнадцатого достаточно строк с пометкой «победа сразу». Минимальное S в этой колонке и есть ответ.

План девятнадцатого

  1. Выписываем команды.
  2. Для каждого S считаем, куда ведёт каждая команда.
  3. Если хотя бы один результат не меньше границы — из этого S побеждают первым ходом.
  4. Среди таких S берём наименьшее.

Пример 1. Три команды, граница 25

Вопрос. Команды: +1, +2, ×2. Победа, если камней стало не меньше 25. Какое наименьшее S даёт Пете победу первым ходом?

Умножение на 2 обгоняет прибавление. 12×2 = 24, это ещё меньше 25. 13×2 = 26, уже хватает. Прибавить 1 до 25 можно только из 24, это больше тринадцати. Поэтому минимальное S — 13, за счёт удвоения.

Пример 2. Другие команды, граница 30

Вопрос. Команды: +1, +4, ×3. Граница 30. Наименьшее S, с которого первый же ход побеждает?

Из 9: 9+1 = 10, 9+4 = 13, 9×3 = 27. Тридцати нет. Из 10: 10×3 = 30, этого достаточно. Прибавления догоняют границу только у больших куч, они минимальными не будут.

Коротко, чтобы запомнить

  1. Девятнадцатое — про один ход Пети, без длинной стратегии.
  2. Победа, если результат команды не меньше границы. «Больше» и «не меньше» в условии читают внимательно; в наших примерах граница входит.
  3. Проверяем все команды, не только самую большую.
  4. Ответ — минимальное такое S, не список всех.

Победа первым ходом

Задания 19, 20 и 21 — одна игра. Здесь нужен только первый вопрос: наименьшее S, из которого хотя бы одна команда сразу перешагивает границу.

В списке adds — что прибавляют, в mults — на что умножают, limit — граница. Функции task20 и task21 оставлены в том же файле, чтобы на следующих уроках менять только вызов, не правила.

Рабочие программы к этому уроку

Каждый фрагмент запускается отдельно. В конце он печатает ответ. Комментарии на русском говорят, какая строка за что отвечает.

n19-25

def moves_of(s, adds, mults):
    result = [s + step for step in adds]
    result += [s * factor for factor in mults]
    return result

def win_now(s, limit, adds, mults):
    return any(nxt >= limit for nxt in moves_of(s, adds, mults))

def task19(limit, adds, mults):
    # Наименьшее S, откуда первый ход сразу побеждает.
    s = 1
    while True:
        if s < limit and win_now(s, limit, adds, mults):
            return s
        s += 1

def task20(limit, adds, mults):
    # Петя сразу не побеждает, но любой его ход отдаёт победу Ване.
    s = 1
    while s < limit:
        if not win_now(s, limit, adds, mults):
            nxt = [x for x in moves_of(s, adds, mults) if x < limit]
            if nxt and all(win_now(x, limit, adds, mults) for x in nxt):
                return s
        s += 1
    return None

def task21(limit, adds, mults):
    # Два наименьших S, откуда Петя побеждает своим вторым ходом.
    found = []
    s = 1
    while len(found) < 2 and s < limit:
        if not win_now(s, limit, adds, mults):
            for t in moves_of(s, adds, mults):
                if t >= limit:
                    continue
                vanya = [u for u in moves_of(t, adds, mults)]
                # Любой ход Вани ещё не победа, но после него Петя побеждает сразу.
                if vanya and all(
                    u < limit and win_now(u, limit, adds, mults) for u in vanya
                ):
                    found.append(s)
                    break
        s += 1
    return int("".join(str(x) for x in found))

limit = 25  # МЕНЯТЬ: граница
adds = [1, 2]  # МЕНЯТЬ: что прибавляют
mults = [2]  # МЕНЯТЬ: на что умножают
print(task19(limit, adds, mults))
