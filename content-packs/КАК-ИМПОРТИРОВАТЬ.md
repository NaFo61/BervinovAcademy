# Как загрузить уроки ЕГЭ на сайт

Архивы уже собраны. Программировать ничего не нужно. На сайт загружается **по одному ZIP**.

Папка с файлами:

`content-packs/к-импорту/`

Там 30 архивов: `01-ege-n1-import.zip` … `27-ege-n27-import.zip`, затем три контрольные `28` … `30`. Берите их **сверху вниз**.

Текст теории уже внутри каждого архива. Отдельные файлы `theory.html` загружать не нужно.

## Куда на сайте

Сайт: https://academy.bervinov-miron.ru/#/mentor

1. Войдите как **ментор или администратор** (не как ученик).
2. Откройте пункт **Ментор**.
3. В списке **Курс** выберите **«ЕГЭ-информатика»**.
4. Нажмите вкладку **Редактор** (сначала открыта вкладка «Курсы» — её пропустите).
5. Раскройте зелёный блок **«Импорт пакета заданий»**.
6. Перетащите **один** ZIP или нажмите и выберите файл.
7. Нажмите **«Проверить (без записи)»**.
8. Если в списке есть теория — нажмите **«Импортировать в курс»**.
9. Повторите шаги 6–8 для следующего файла, пока не дойдёте до 27.

Повторная загрузка того же файла **не создаёт копии**: урок с тем же названием обновляется.

## Что должно быть на проверке

| Файлы | Что увидите после «Проверить» |
|-------|--------------------------------|
| `01` … `15` | теорию и вопросы |
| `16` … `27` | теорию и вопросы к этому номеру |
| `28` … `30` | контрольные: после номеров 1–9, 10–18 и 19–27 |

В задании 1 в списке должно быть «Задание 1 ЕГЭ: графы».  
В задании 16 — «Задание 16 ЕГЭ: рекурсия». Если названия есть, текст на месте.

Новые уроки встают **в конец** курса, в том порядке, в каком вы их загрузили. Поэтому идите с 01 до 30. Сначала номера, потом контрольные.

Старый урок «3-й урок ЕГЭ: Электронные таблицы» остаётся. Задание 9 — это **другой**, новый урок. В уроках 1, 2 и 4 могут остаться старые учебные вопросы: пакет их не удаляет, а добавляет новые. Старые можно скрыть в редакторе (выключить «активен»).

Видео в архивах нет. Их можно прикрепить потом в редакторе урока.

## Если кнопки импорта нет

На сервере, в папке `/opt/bervinov-academy`, для **одного** файла (пример — задание 1):

```
docker compose cp /путь/к/01-ege-n1-import.zip backend:/tmp/pack.zip
docker compose exec -T backend python manage.py import_content_pack /tmp/pack.zip
```

Проверка без записи в базу:

```
docker compose exec -T backend python manage.py import_content_pack /tmp/pack.zip --dry-run
```

Дальше то же самое для 02, 03 и так до 27. Если курс ещё не создан:

```
docker compose exec -T backend python manage.py ensure_ege_course
```

## Чего не делать

- Не загружайте все ZIP одним разом и не используйте общий `content-packs.zip`. Сайт принимает один пакет за раз.
- Не запускайте на сервере `full-restart`: он стирает базу.
- Не загружайте `theory.html` отдельно. Текст уже внутри ZIP.
