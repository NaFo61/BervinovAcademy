Страница для проверки. Сверху теория со схемами, ниже задания. Разбор всех задач — внизу, по шагам.

Что дают в задании 9

Дают файл с числами: в каждой строке несколько натуральных чисел. Нужно найти строки, которые подходят под оба условия, и посчитать сумму или номер.

В 2026 году файл — это .ods. Его открывают в LibreOffice Calc. Формулы те же, что привыкли видеть в таблицах: СЧЁТЕСЛИ, СРЗНАЧЕСЛИ, СУММ.

Маленькая таблица, те же условия

В каждой строке пять чисел. Строка подходит, если:

  • одно число повторяется три раза, а два других встречаются по одному разу;
  • среднее двух неповторяющихся чисел не больше, чем повторяющееся.

Задача 1. Какие строки подходят

  1. Строка 1: три четвёрки, рядом 1 и 9. Среднее (1 + 9) / 2 = 5. Пять больше 4, строка не подходит.
  2. Строка 2: три двойки, рядом 5 и 8. Среднее 6,5 больше 2. Не подходит.
  3. Строка 3: три семёрки, рядом 3 и 5. Среднее 4, и 4 не больше 7. Подходит. Сумма 29.
  4. Строка 4: все числа разные. Тройки нет. Не подходит.
  5. Строка 5: три шестёрки, рядом 1 и 2. Среднее 1,5 не больше 6. Подходит. Сумма 21.
  6. Строка 6: три девятки, рядом 4 и 8. Среднее 6 не больше 9. Подходит. Сумма 39.

Подходящих строк три. У строки с наибольшим номером сумма 39.

Задача 2. Как это увидеть формулой

Для пяти клеток с одной тройкой и двумя разными числами счётчики дают 3, 3, 3, 1, 1. Их сумма равна 11. Если сумма другая, тройка не одна или числа другие.

Потом СРЗНАЧЕСЛИ берёт среднее только тех чисел, которые встретились один раз, и сравнивает его с тройкой.

Как решать

  1. Открыть .ods в Calc.
  2. СЧЁТЕСЛИ по каждой клетке строки: сколько раз это число повторилось.
  3. Оставить строки, где счётчики складываются в 3 + 3 + 3 + 1 + 1.
  4. Проверить среднее одиночных чисел и взять нужную строку: обычно последнюю подходящую.

Строки файла циклом

В Calc то же самое делает СЧЁТЕСЛИ. В программе у каждой строки считают, сколько раз встретилось каждое число. Подходящая пятёрка даёт счётчики 3, 3, 3, 1, 1. Их сумма 11. Потом среднее двух одиночных сравнивают с повторяющимся числом.

В ответ обычно берут сумму последней подходящей строки, не сумму всего листа.

Рабочие программы к этому уроку

Каждый фрагмент запускается отдельно. В конце он печатает ответ. Комментарии на русском говорят, какая строка за что отвечает.

Строка таблицы: тройка повторов и среднее одиночных.

rows = [
    # МЕНЯТЬ: числа из файла. Здесь учебная таблица из теории.
    [4, 4, 4, 1, 9],
    [2, 2, 2, 5, 8],
    [7, 7, 7, 3, 5],
    [1, 2, 3, 4, 5],
    [6, 6, 6, 1, 2],
    [9, 9, 9, 4, 8],
]

def fits(row):
    counts = [row.count(x) for x in row]
    if sorted(counts) != [1, 1, 3, 3, 3]:
        return False
    triple = [x for x in row if row.count(x) == 3][0]
    singles = [x for x in row if row.count(x) == 1]
    average = sum(singles) / len(singles)
    return average <= triple  # МЕНЯТЬ: знак сравнения из условия

good = [row for row in rows if fits(row)]
print(sum(good[-1]))  # последняя подходящая

Что менять, если условие другое.

  • # МЕНЯТЬ: числа из файла. Здесь учебная таблица из теории.
  • return average <= triple # МЕНЯТЬ: знак сравнения из условия
  • Печать в конце оставляют: это и есть ответ.

Программа печатает 39.

Сколько строк проходят оба условия.

rows = [
    [4, 4, 4, 1, 9],
    [2, 2, 2, 5, 8],
    [7, 7, 7, 3, 5],
    [1, 2, 3, 4, 5],
    [6, 6, 6, 1, 2],
    [9, 9, 9, 4, 8],
]

def fits(row):
    counts = [row.count(x) for x in row]
    if sorted(counts) != [1, 1, 3, 3, 3]:
        return False
    triple = [x for x in row if row.count(x) == 3][0]
    singles = [x for x in row if row.count(x) == 1]
    return sum(singles) / len(singles) <= triple

print(sum(1 for row in rows if fits(row)))

Что менять, если условие другое.

  • Числа в первых строках — это данные условия. Цикл и формулу вокруг них не переписывают.
  • Печать в конце оставляют: это и есть ответ.

Программа печатает 3.
