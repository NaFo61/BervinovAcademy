Задание 21 ЕГЭ: Петя побеждает своим вторым ходом

Снова та же игра. Теперь Петя первым ходом границу не берёт. Но у него есть ход в такую кучу, которую мы в задании 20 назвали проигрышной для того, кто на ней оказался. Ваня на ней вынужден отдать Пете мгновенную победу. То есть партия кончается на втором ходе Пети, и Ваня этому не мешает: все его ответы всё равно проигрышные.

В ответ обычно просят два наименьших таких S, записанных по возрастанию без пробела.

Игрушка: граница 10

Проигрышная куча у нас одна: 4. Из неё Ваня что ни сделает, Петя сразу заканчивает. Значит Пете полезно своим первым ходом попасть ровно в 4.

Кто может прийти в 4? Команда +1 приходит из 3. Команда ×2 приходит из 2. Из двойки Петя ещё не побеждает сразу: 2+1 = 3, 2×2 = 4, до десятки далеко. Он выбирает умножение, оставляет Ване 4, и на своём втором ходе забирает игру. Из тройки он прибавляет единицу и тоже оставляет 4. Оба стартовых числа подходят. По возрастанию это 2 и 3, в бланк пишут 23.

План. Находим проигрышные кучи из задания 20. Смотрим, из каких S в них есть ход. Выбрасываем те S, откуда и так побеждают за один ход: в двадцать первом такие не нужны. Оставшиеся пишем по возрастанию.

Пример 1. Граница 25

Вопрос. Команды +1, +2, ×2, граница 25. Два наименьших S, с которых Петя побеждает своим вторым ходом. Запишите их подряд.

Проигрышная куча — 12. В неё можно прийти так: 11+1, 10+2, 6×2. Из 11, 10 и 6 мгновенной победы нет, все три левее 13. Два наименьших — 6 и 10. Одиннадцать тоже подходит, но в ответ просят два наименьших, её не берём.

Проверим шестёрку руками. Ходы: 7, 8 и 12. Петя выбирает 12, не 7 и не 8. Ваня из 12 вынужден пойти в 13, 14 или 24. Из любой Петя уже умеет перейти 25. Если Петя с шестёрки по ошибке уйдёт в 7, план ломается. В задании считается, что оба играют лучшим образом, поэтому Петя выберет 12.

Пример 2. Граница 30

Вопрос. Команды +1, +4, ×3, граница 30. Два наименьших S подряд.

Проигрышная куча — 9. В неё попадают: 8+1, 5+4 и 3×3. Из 3, 5 и 8 первым ходом до 30 не дотянуться. Два наименьших — 3 и 5. Восьмёрка третья, в эти два места она не входит.

Из тройки Петя умножает на 3 и оставляет 9. Дальше любой ход Вани, и Петя заканчивает. Из пятёрки Петя прибавляет 4 и тоже оставляет 9.

Коротко, чтобы запомнить

  1. Сначала кучи «победа сразу», потом кучи «любой ход туда ведёт», и только потом кучи «можно шагнуть в проигрыш».
  2. Петя не обязан каждым ходом идти в проигрышную кучу. Достаточно, что такой ход у него есть, и при лучшей игре он его выберет.
  3. Кучи, откуда и так побеждают за один ход, в это задание не входят.
  4. Два наименьших пишем по возрастанию, без пробела и запятой.

Победа вторым ходом Пети

Петя первым ходом не заканчивает игру. Зато у него есть ход в такую кучу, что любой ответ Вани оставляет Пете немедленную победу. Берут два наименьших таких S и записывают подряд, без пробела и запятой.

Это всё ещё те же команды. Меняют границу и списки ходов. Печатает task21.

Рабочие программы к этому уроку

Каждый фрагмент запускается отдельно. В конце он печатает ответ. Комментарии на русском говорят, какая строка за что отвечает.

n21-25

def moves_of(s, adds, mults):
    result = [s + step for step in adds]
    result += [s * factor for factor in mults]
    return result

def win_now(s, limit, adds, mults):
    return any(nxt >= limit for nxt in moves_of(s, adds, mults))

def task19(limit, adds, mults):
    # Наименьшее S, откуда первый ход сразу побеждает.
    s = 1
    while True:
        if s < limit and win_now(s, limit, adds, mults):
            return s
        s += 1

def task20(limit, adds, mults):
    # Петя сразу не побеждает, но любой его ход отдаёт победу Ване.
    s = 1
    while s < limit:
        if not win_now(s, limit, adds, mults):
            nxt = [x for x in moves_of(s, adds, mults) if x < limit]
            if nxt and all(win_now(x, limit, adds, mults) for x in nxt):
                return s
        s += 1
    return None

def task21(limit, adds, mults):
    # Два наименьших S, откуда Петя побеждает своим вторым ходом.
    found = []
    s = 1
    while len(found) < 2 and s < limit:
        if not win_now(s, limit, adds, mults):
            for t in moves_of(s, adds, mults):
                if t >= limit:
                    continue
                vanya = [u for u in moves_of(t, adds, mults)]
                # Любой ход Вани ещё не победа, но после него Петя побеждает сразу.
                if vanya and all(
                    u < limit and win_now(u, limit, adds, mults) for u in vanya
                ):
                    found.append(s)
                    break
        s += 1
    return int("".join(str(x) for x in found))

print(task21(25, [1, 2], [2]))

Что менять, если условие другое.

  • Числа в первых строках — это данные условия. Цикл и формулу вокруг них не переписывают.
  • Печать в конце оставляют: это и есть ответ.

Программа печатает 610.
