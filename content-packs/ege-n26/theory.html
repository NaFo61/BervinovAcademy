Задание 26 ЕГЭ: файлы на диске

Есть диск известного объёма и набор файлов. Файл кладут целиком или не кладут никак. Спрашивают две вещи. Сколько файлов удастся записать, если хотим как можно больше штук. И какой самый большой файл можно при этом сохранить — не один на весь диск, а в наборе, где файлов столько же, сколько в самом плотном по количеству.

Больше всего штук набирается с самых маленьких. Крупный файл, положенный первым, съест место трёх мелких.

Игрушка: диск на 10

Файлы 3, 6, 2 и 4. Сортируем по возрастанию: 2, 3, 4, 6.

файлрешениезанятосвободно
2берём28
3берём55
4берём91
6не берём91

2+3+4 = 9, свободно 1. Шестёрка не входит. Файлов три. Второй вопрос: можно ли заменить кого-то из этих трёх так, чтобы крупнейший в наборе стал больше 4, а сумма всё ещё не превосходила 10?

Мелочь 2 и 3 оставляем, это 5, свободно 5. Четвёрка в эти пять входит, шестёрка нет: 5+6 = 11. Крупнее четвёрки положить нечего. Самый большой файл так и остаётся 4.

Файлов: 3. Самый большой среди них: 4

План

  1. Сортируем размеры по возрастанию.
  2. Берём с маленьких, пока следующий ещё входит. Это максимум штук.
  3. Для второго вопроса откладываем последний взятый: он самый крупный в этом наборе.
  4. Смотрим, какое самое большое число из всего списка всё ещё входит в освободившееся место.
  5. Один убрали, один положили. Количество файлов не меняется.

Пример 1. Диск на 100

Вопрос. Диск 100. Файлы: 15, 8, 22, 7, 30, 11, 9, 18, 6, 25. Сколько файлов можно записать? Какой наибольший размер файла достижим в наборе с этим же количеством?

Порядок такой: 6, 7, 8, 9, 11, 15, 18, 22, 25, 30.

7берём1387

11берём4159
15берём5644
18берём7426
22берём964
25не берём964
30не берём964

Восемь файлов занимают 96, свободно 4. Число 25 уже не входит. Количество — 8.

Откладываем 22. Без него занято 74, свободно 26. В эти 26 входят 22 и 25. Тридцать не входит: 74+30 = 104. Заменяем 22 на 25. Файлов по-прежнему восемь, сумма 96 − 22 + 25 = 99.

Файлов: 8. Наибольший файл в таком наборе: 25

Пример 2. Замена видна на маленьком диске

Вопрос. Диск 20. Файлы: 9, 6, 5, 14, 4. Те же два числа в ответе.

файлрешениезанятосвободно
4берём416
5берём911
6берём155
9не берём155
14не берём155

Три файла: 4+5+6 = 15. Если шестёрку уже положили, девятка не входит. Откладываем шестёрку. Остаются 4 и 5, занято 9, свободно 11. В одиннадцать входят 6 и 9. Четырнадцать не входит: 9+14 = 23. Берём 9. Набор 4, 5 и 9 занимает 18. Файлов по-прежнему три, крупнейший уже не 6, а 9.

Файлов: 3. Наибольший файл в таком наборе: 9

Коротко, чтобы запомнить

  1. Максимум штук даёт набор с самых маленьких файлов.
  2. Файл не режут. Не влез очередной в отсортированном списке — более крупные тоже не влезут.
  3. Второй вопрос не начинается с самого большого файла в одиночку: так штук станет меньше.
  4. Меняем только крупнейший в уже набранном комплекте.

Сначала мелкие файлы

Максимум штук набирается с самых маленьких размеров. Список сортируют по возрастанию и берут, пока сумма не вылезет за диск.

Второй вопрос: в наборе с тем же количеством сделать наибольший файл как можно крупнее. Снимают последний взятый — он самый большой в жадном наборе — и смотрят, какое более крупное число ещё входит в освободившееся место. Количество файлов при замене не меняется.

Рабочие программы к этому уроку

Каждый фрагмент запускается отдельно. В конце он печатает ответ. Комментарии на русском говорят, какая строка за что отвечает.

n26-toy

disk = 10  # МЕНЯТЬ: объём диска
files = [3, 6, 2, 4]  # МЕНЯТЬ: размеры
files = sorted(files)
taken = []
used = 0
for size in files:
    if used + size <= disk:
        taken.append(size)
        used += size
# Снимаем самый большой из взятых и ищем, кого можно положить вместо него.
without = used - taken[-1]
biggest = taken[-1]
for size in reversed(files):
    if without + size <= disk and size > biggest:
        biggest = size
        break
print(len(taken), biggest)

Что менять, если условие другое.

  • disk = 10 # МЕНЯТЬ: объём диска
  • files = [3, 6, 2, 4] # МЕНЯТЬ: размеры
  • Печать в конце оставляют: это и есть ответ.

Программа печатает 3 4.
