Что дают на экзамене

Рядом две вещи. Слева схема: города буквами, между ними дороги. Справа таблица: те же города, но под номерами. Какая буква какому номеру равна, не подписано. Это и надо восстановить.

Число линий из точки называют степенью. На экзамене слово можно не писать. Ищем не «центральную» точку, а точку с редким числом дорог. Если число встретилось один раз, это якорь: буква и номер — одна и та же вершина.

В таблице звёздочка или число значит, что дорога есть. Пустая клетка — дороги нет. По диагонали всегда пусто. Дорога 2—4 и дорога 4—2 — одна и та же, в сумму её берут один раз.

Приём 1. Два номера

Спрашивают номера двух букв. В ответе две цифры по возрастанию. Сначала якоря, потом соседи, если букв с одинаковым числом несколько.

Пример. Какие номера у пунктов A и B? Запишите две цифры по возрастанию, без пробела.

  1. У пункта A дорог 4, и такое число на схеме одно. В таблице столько же только у пункта 1. Значит A = 1.
  2. У пункта B дорог 3, и такое число на схеме одно. В таблице столько же только у пункта 2. Значит B = 2.
  3. У пункта E дорог 1, и такое число на схеме одно. В таблице столько же только у пункта 5. Значит E = 5.
  4. Из уже найденных соседей пункта C есть номера 1. Так же связан только пункт 3. Значит C = 3.
  5. Из уже найденных соседей пункта D есть номера 1, 2. Так же связан только пункт 4. Значит D = 4.
  6. Из уже найденных соседей пункта F есть номера 2. Так же связан только пункт 6. Значит F = 6.
  7. Пункт A — это номер 1. Пункт B — это номер 2. По возрастанию получается 12.

Ответ: 12.

Программа

Нажмите «В интерпретатор» под кодом. Программу можно менять и запускать заново.

from collections import Counter
letters = {'A': 4, 'B': 3, 'C': 2, 'D': 2, 'E': 1, 'F': 2}  # МЕНЯТЬ: сколько дорог у буквы
rows = {1: 4, 2: 3, 3: 2, 4: 2, 5: 1, 6: 2}  # МЕНЯТЬ: сколько отметок в строке таблицы
once = {deg for deg, cnt in Counter(letters.values()).items() if cnt == 1}
for name, deg in letters.items():
    if deg not in once:
        continue
    nums = [num for num, got in rows.items() if got == deg]
    print(name, nums[0])

# Редкие степени печатаются как «буква номер».
# Номера пунктов A и B запишите двумя цифрами по возрастанию.

Приём 2. Сумма по якорям

В таблице уже километры. Нужные буквы видны по редкому числу дорог. Дальше в таблице на пересечении их номеров читают длины и складывают.

Пример. Найдите сумму длин дорог A—C и C—E. Только число.

  1. У пункта A дорог 3, и такое число на схеме одно. В таблице столько же только у пункта 1. Значит A = 1.
  2. У пункта C дорог 4, и такое число на схеме одно. В таблице столько же только у пункта 3. Значит C = 3.
  3. У пункта E дорог 1, и такое число на схеме одно. В таблице столько же только у пункта 5. Значит E = 5.
  4. Из уже найденных соседей пункта B есть номера 1, 3. Так же связан только пункт 2. Значит B = 2.
  5. Из уже найденных соседей пункта D есть номера 1. Так же связан только пункт 4. Значит D = 4.
  6. Из уже найденных соседей пункта F есть номера 3. Так же связан только пункт 6. Значит F = 6.
  7. Дорога A—C стоит между пунктами 1 и 3: это 7. Дорога C—E стоит между пунктами 3 и 5: это 13. Сумма 7 + 13 = 20.

Ответ: 20.

Приём 3. Сначала сосед тупика

Тупик — пункт с одной дорогой. Его номер часто виден сразу. Сосед тупика среди нескольких похожих пунктов один: в таблице он связан с номером тупика. Потом читают две длины и складывают.

Пример. Найдите сумму длин дорог E—F и F—C. Только число.

  1. У пункта E дорог 1, и такое число на схеме одно. В таблице столько же только у пункта 5. Значит E = 5.
  2. Из уже найденных соседей пункта F есть номера 5. Так же связан только пункт 6. Значит F = 6.
  3. У пункта A дорог 3, и такое число на схеме одно. В таблице столько же только у пункта 1. Значит A = 1.
  4. У пункта B дорог 2, и такое число на схеме одно. В таблице столько же только у пункта 2. Значит B = 2.
  5. Из уже найденных соседей пункта C есть номера 6. Так же связан только пункт 3. Значит C = 3.
  6. Из уже найденных соседей пункта D есть номера 6. Так же связан только пункт 4. Значит D = 4.
  7. Дорога E—F стоит между пунктами 5 и 6: это 17. Дорога F—C стоит между пунктами 6 и 3: это 13. Сумма 17 + 13 = 30.

Ответ: 30.
